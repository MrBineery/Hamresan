# Hamresan — هم‌رسان

> انتقال فایل روی شبکه محلی — بدون اینترنت، بدون سرور، بدون محدودیت حجم.

**Hamresan** lets you share files and text between devices on the same local network (Wi-Fi, hotspot, LAN) using a fast web interface. No cloud, no account, no size limit.

## ✨ ویژگی‌ها

- 📁 انتقال فایل با حجم نامحدود
- 📋 اشتراک متن و لینک (clipboard)
- 🔐 محافظت با PIN
- 🌐 بدون نیاز به اپلیکیشن — فقط مرورگر
- 📱 کار روی اندروید، آیفون، ویندوز، مک، لینوکس
- 🖥️ اپلیکیشن دسکتاپ برای ویندوز
- 🌓 تم تاریک/روشن
- 🌍 دو زبانه (فارسی / انگلیسی)

## ⚙️ طرز کار

### ۱. اجرای برنامه
فایل اجرایی Hamresan را روی یکی از دستگاه‌ها (مثلاً لپ‌تاپ) اجرا کنید.

### ۲. اتصال به شبکه محلی
مطمئن شوید همه دستگاه‌ها به یک شبکه مشترک وصل هستند — Wi-Fi، هات‌اسپات یا LAN.

### ۳. دریافت آدرس و PIN
برنامه یک آدرس (مثلاً `http://192.168.1.5:8080`) و یک PIN نمایش می‌دهد.

### ۴. اتصال از دستگاه‌های دیگر
روی موبایل، تبلت یا کامپیوتر دیگر، همان آدرس را در مرورگر باز کنید.

### ۵. ورود PIN
پین نمایش داده شده در قسمت بالا سمت چپ را وارد کنید تا دسترسی امن برقرار شود.

### ۶. انتقال فایل یا متن
فایل‌ها را انتخاب کنید، متن یا لینک را پیست کنید — انتقال مستقیم و بدون محدودیت حجم انجام می‌شود.

> 🔒 تمام داده‌ها فقط روی شبکه محلی جابه‌جا می‌شوند و هیچ اطلاعاتی به اینترنت یا سرور خارجی ارسال نمی‌شود.
